# Security Policy

CodeFlow is a prototype learning application and is not designed for sensitive data.

## Reporting a vulnerability

Please do not publish credentials, API keys, or exploitable details in a public issue. Use GitHub's private security reporting mechanism if it is enabled for this repository; otherwise contact the maintainer privately through the GitHub profile.

## Scope

Security reports involving dependency vulnerabilities, unsafe client-side behavior, exposed credentials, or unintended execution capabilities are welcome.

Never include real personal, medical, financial, or authentication data in examples or bug reports.
