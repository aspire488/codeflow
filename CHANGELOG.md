# Changelog

All notable changes to CodeFlow are documented here.

## [1.1.0] - 2026-09-10

### Added

- Execution-first programming learning prototype with visible code behavior
- Deterministic test and production-build validation in GitHub Actions
- Engineering architecture and testing documentation
- Public prototype safety and contribution guidance
- Automated dependency update configuration

### Engineering notes

- The execution model remains intentionally educational and bounded.
- AI assistance is experimental and does not replace deterministic execution.
- AST-backed execution is the next major engineering milestone.

### Known limitations

- Browser-level regression coverage is still being expanded.
- The project is not a general-purpose programming-language interpreter.
