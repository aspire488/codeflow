# Bundled fonts

- `inter-latin*.woff2` is Inter from Google Fonts, variable weights 400-700. Source: https://fonts.google.com/specimen/Inter. License: SIL Open Font License 1.1, included as `Inter-OFL.txt`.
- `material-symbols-outlined.woff2` is Material Symbols Outlined, weight 400. Source: https://fonts.google.com/icons. License: Apache License 2.0, included as `Material-Symbols-Apache-2.0.txt`.

The files are self-hosted to keep the visual system consistent in offline use and in environments that block third-party font hosts.
